# Claude entry — REST Engine

REST is a deterministic JSON-driven rap-techno production engine. It uses a 5-color consciousness model (radical.grey, radical.blue, radical.green, radical.cream, radical.black), JSON as single source of truth, and Python only as tooling. Active tracks live in `tracks/`; legacy 7-sin material is read-only under `chatgpt/rest/_quarantine_legacy_7id/`. Identity and behavior are defined in the repo; this folder is the Claude-facing documentation layer only.

**First action on entry:** Run `python python/validate.py` from repo root. If FAIL: report path and reason, then stop. If PASS: proceed only within explicitly requested scope.
